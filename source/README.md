# 奶龙动画原画

本目录保存奶龙的全身定稿和无损 WebP 动作原画。每张动作条从左到右排列，同一帧的头、四肢和尾巴应一起提取。

| 文件 | 内容 | 帧数 |
| --- | --- | ---: |
| `base.webp` | 正面全身定稿，用来对照角色比例和配色 | 1 |
| `idle.webp` | 待机、眨眼和呼吸 | 6 |
| `running-right.webp`、`running-left.webp` | 向右和向左跑动。向左动作由向右动作逐帧镜像，帧序相同 | 各 8 |
| `waving.webp` | 挥手打招呼 | 4 |
| `jumping.webp` | 捧着肚子笑得蹦起来，落地后侧身弯腰大笑，再直起身 | 5 |
| `failed.webp` | 遇到挫折时的反应 | 8 |
| `waiting.webp` | 摊开双手等待回应 | 6 |
| `running.webp` | 正在工作时抱臂思考 | 6 |
| `review.webp` | 检查工作结果 | 6 |
| `look-cardinals.webp` | 向上、向屏幕右、向下、向屏幕左的四个参考姿势 | 4 |
| `look-row-9.webp` | 从正上方起顺时针注视，0° 至 157.5° | 8 |
| `look-row-10.webp` | 接着从正下方转向左侧，180° 至 337.5° | 8 |
| `laugh.webp` | 完整的捧腹大笑分镜，包含腾空时露出脚底、落地侧身大笑和站直收势 | 8 |
| `laugh-keys.png` | 已去底并对齐的八个透明关键帧，可直接用来渲染独立大笑动画 | 8 |

### 提取与排列

以纯洋红色 `#FF00FF` 为色键去除背景，将轮廓边缘的洋红色残边一并清理。按完整角色轮廓从左到右提取每帧，同一动作使用统一缩放比例。保留跳跃动作各帧脚底的相对高度。

从左到右把 `laugh.webp` 的八个姿势编号为 1 到 8。`jumping.webp` 选用了第 **1、3、5、6、8** 帧，保留原画像素，并按宠物播放时的位置重新排列。最终每格为 192 × 208 像素时，第 3 个原画姿势的脚底比落地时高 13 像素。

制作 v2 精灵图时，每格使用 192 × 208 像素，每行八格。先按表中顺序放入九种标准动作，向右跑和向左跑各占一行，再放入两行连续注视姿势。每行动作靠左排列，未使用的格子保持透明。全身定稿和四向参考姿势仅供对照。
